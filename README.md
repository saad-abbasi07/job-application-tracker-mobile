# Job Application Tracker Mobile

A React Native mobile app for tracking job applications.

## Features

- Register and Login
- JWT Authentication
- Add Job Applications
- Edit Applications
- Delete Applications
- Search Applications
- Filter by Status
- Profile Information
- Job Notes and Job URL
- Logout
- Android APK Build

## Tech Stack

- React Native
- Expo
- TypeScript
- NativeWind
- Expo Router
- Axios
- Expo SecureStore
- Node.js
- Express.js
- MongoDB Atlas
